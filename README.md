# Calibre Enhanced Edition

Custom Selection Highlight Colors + Piper Neural TTS for Calibre 9.14

## Features

- Custom selection highlight background color
- Custom selection text color
- Piper Neural TTS (Read Aloud)
- Arch Linux tested

## Usage

    python3 launch-calibre.py

Open a book, Settings gear, Colors, + New scheme, set your colors.

## Install

    git clone https://github.com/LRM45/calibre-enhanced.git
    cd calibre-enhanced
    python3 launch-calibre.py

## Build

    python3 setup.py rapydscript
